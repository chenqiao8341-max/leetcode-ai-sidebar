# 力扣伴读 · DeepSeek（Microsoft Edge 扩展）

这是可以直接“加载解压缩的扩展”的源码版本。无需安装 Node.js、Python 或运行服务器。

## 0.4.0 更新：统一设置与主题切换

- 右上角点击“设置”，进入“外观、模型、教学、关于”四个分类。后续功能可以继续加入这个设置入口。
- “外观”提供清透浅色、石墨深色（深灰底白字）、暖纸阅读、雾紫柔光，以及跟随系统自动切换浅色 / 深色。
- 点击主题立即预览并自动保存；刷新、关闭侧栏或重启浏览器后继续使用所选主题。主题独立保存，不改动密钥、模型、教学提示词或对话记录。
- 代码块、公式、表格、输入框、消息气泡和设置窗口均适配主题；切换外观不会调用模型接口。
- “模型”管理 DeepSeek 连接，“教学”管理系统提示词。这两类修改仍需点击“保存模型与教学设置”。

更新方式：在 `edge://extensions` 找到本扩展，点击“重新加载”，关闭并重新打开侧栏。无需卸载，已保存的对话会保留。如果安装时另行复制了文件夹，先用新版覆盖实际加载的目录。未记住的会话密钥可能需要重新输入。

## 0.3.0 更新：对话保存与浅色界面

- 修复离开力扣页面时清空对话的问题。切到普通网页只暂停页面读取，保留原题对话和输入草稿；切回后使用最新代码继续提问。侧栏保持打开时，已发出的回答可以在切到普通网页后继续生成。
- 按题目网址分别保存完整显示记录、最近 4 轮模型上下文、输入草稿、教学模式和手动代码。切换到另一道题不会把两题的对话混在一起；切回会恢复该题记录。同一道题的不同标签页共享该题记录。
- 对话保存在扩展本地存储中。关闭并重新打开侧栏、重启浏览器后，打开相应题目即可恢复。无需新增权限，不上传到额外服务器。
- 换到另一道题时，正在生成的回答会停止，已生成的部分保留在原题中并标注中断。关闭侧栏也会中断当前请求，恢复后可继续提问。
- “清空本题对话”只清空当前题目的消息及模型历史，不影响其他题目，也不会自动清除输入草稿或手动代码。
- 界面改为浅色底、灰黑文字与少量蓝色强调，调整图标、气泡、输入框和内容间距；保留 Markdown 与公式渲染。

更新方式：在 `edge://extensions` 中点击本扩展的“重新加载”，关闭并重新打开侧栏，刷新力扣网页。原目录已更新；如果你另行复制过扩展，先覆盖实际加载的目录。**旧版没有保存到本机的历史，无法通过本次更新恢复。**

本机存储有容量限制，保存失败时会显示“本机保存失败，请勿关闭侧栏”，不会悄悄清理其他题目的记录。多窗口同时编辑同一题时使用同一个存储记录，建议在一个窗口中继续该题，以免彼此覆盖。

## 0.2.0 更新：Markdown 与数学公式

已经安装旧版时：在 `edge://extensions` 找到“力扣伴读 · DeepSeek”，点击“重新加载”，关闭并重新打开侧栏，刷新力扣网页。不需要卸载扩展。若安装时另行复制了解压目录，请先把新版文件覆盖到你实际加载的目录。

- 完整排版常用 Markdown：标题、粗体、斜体、删除线、有序/无序列表、嵌套列表、引用、表格、链接、分隔线和代码块。
- 使用 KaTeX 显示行内与行间公式，支持 `$…$`、`$$…$$`、`\(...\)`、`\[...\]`，包括分数、求和、上下标与对齐公式。
- 公式在流式输出尚未闭合时保留文字，闭合后渲染；代码块和行内代码里的公式符号保持原样。
- 代码块显示语言标签和“复制”按钮。长代码、表格、公式支持局部横向滚动。
- 所有渲染库和字体随扩展本地打包，无需访问外部 CDN。依赖版本与许可证见 `vendor/`。
- 自定义系统提示词、模型设置保持原存储方式。未勾选“记住密钥”时，重新加载扩展可能会清空会话密钥，需要再次输入。

LaTeX 支持范围以 KaTeX 为准；不支持的命令或格式错误会显示原始内容/提示颜色，不会使整段回答消失。模型返回的原始 HTML 不执行，外部图片不自动加载。

## 安装：约 2 分钟

1. 在 **Microsoft Edge 地址栏**输入 `edge://extensions`，按回车。
2. 打开页面上的“开发人员模式”，点击“加载解压缩的扩展”（部分版本显示“加载解压缩”）。
3. 选择下载并解压后的仓库文件夹（或 Git 克隆目录），其中应直接包含 `manifest.json`。不要选择 ZIP 文件或上一级文件夹。

4. 回到力扣题目页面，**刷新网页一次**。点击 Edge 工具栏拼图形状的“扩展”按钮，找到“力扣伴读 · DeepSeek”，点击打开侧栏。可以把它固定到工具栏。
5. 在侧栏“设置 → 模型”中填写自己的 DeepSeek API Key，点击“获取列表”选择账户当前可用的模型，再点击“保存模型与教学设置”。默认模型名为文档当前列出的 `deepseek-flash`，也可以手动修改。

如果使用 ZIP：先解压到长期保留的位置，然后加载解压后含 `manifest.json` 的文件夹。Edge 会直接引用该文件夹，请不要在安装后删除或移动它。

## 需要你人工完成的事项

- 在你正在使用的 Edge 个人配置中完成上述加载操作。
- 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 登录并创建 API Key，自行粘贴到插件中。不要把密钥发到聊天中。
- 如果开放平台没有 API 余额，需要由你自行充值。DeepSeek 网页聊天与 API 账户用量不是同一回事。
- 第一次安装后，在真实力扣页面查看插件“当前上下文”，确认题目与代码内容正确。

## 使用

- 选中一段代码，再在侧栏中问“这里是什么意思”。
- 把编辑器光标放在某一行，再问“这一行为什么这样写”。
- 或直接问“为什么 dfs 传 i 而不是 i+1”“path[:] 和 path 有什么区别”。
- 输入框上方会显示已识别的位置和引用内容。点“查看将发送的上下文”可以检查实际数据。
- “解释这里”“给个提示”“分析复杂度”会填入问题，**点击发送**才会调用 DeepSeek。
- Ctrl+Enter 发送，Shift+Enter 或普通 Enter 换行；可以随时点击“停止”。
- 在设置中编辑系统提示词，可以规定“只给提示”“用具体例子演示递归”等教学方式。编辑后请保存。
- 页面状态约每 1.8 秒在本地刷新；发送前再次读取。离开题目页时暂停读取，返回后获取新代码；不同题目的对话、草稿和手动代码分别保存。
- 对话保存在本机，回到相应题目即可恢复。后续请求仍只携带最近 4 轮有效对话，较早的显示记录不会全部提交给模型。

## 如何判断是否读到了完整代码

| 状态 | 含义 |
|---|---|
| Monaco 编辑器 | 读取编辑器完整代码，并尝试取得光标与选区 |
| Monaco 文本模型（光标未知） | 获取完整代码，但不能可靠定位光标；请在提问里写表达式或行号 |
| CodeMirror 编辑器 | 通过编辑器数据模型取得代码与选区 |
| 仅屏幕可见代码（不完整） | 自动适配失败，只读到当前屏幕显示的行；不能据此推断完整程序 |
| 手动粘贴（不会自动同步） | 使用本题已保存的手动代码；网页修改后需要重新粘贴 |

完整代码自动获取失败时，展开“手动提供完整代码”，在力扣**代码编辑器**中 Ctrl+A、Ctrl+C，粘贴到插件，再勾选“本题使用上面的手动代码”。这只是兼容入口；自动读取成功时不用手动复制。

当前适配了 Monaco 全局接口、已加载的 AMD 模块、编辑器附近的 React ref 和常见 CodeMirror 接口。力扣的前端内部实现可能改变，实际自动读取结果以侧栏显示为准。题目正文和测试区也使用网站选择器适配：未找到时会提示；可在提问里补充报错或测试输入。

## 数据与权限

- 读取范围仅限 `leetcode.cn/problems/*` 与 `leetcode.com/problems/*`。不读取其他网站、不读取 Cookie、不提交或修改代码。
- 点击发送时，将题目正文、当前代码、选区/光标、能读取到的测试区、你的问题及最多最近 4 轮对话发送到 `https://api.deepseek.com/chat/completions`。没有开发者中转服务器或分析统计。
- “获取列表”使用你的密钥访问 DeepSeek 的 `/models` 接口，不发送题目或代码。
- 默认密钥仅保存在浏览器会话存储。勾选“在这台电脑上记住密钥”才会保存到扩展本地存储；该存储不是加密保险库，不使用浏览器云同步。
- 对话文本、输入草稿、模型最近历史、手动粘贴的代码和题目标题保存到扩展本地存储，不使用云同步。清空某题对话不会删除其他题目的记录。
- 网页脚本拿不到扩展保存的密钥。模型输出通过禁用原始 HTML 的 Markdown 解析器和不信任模式的 KaTeX 排版，不执行模型返回的 HTML、脚本或外部图片。
- 对于超长内容，自动代码上限为 60000 字符，题目上限为 22000 字符，测试区上限为 10000 字符；不完整状态会传给模型。

## 常见问题

- **提示刷新网页**：首次加载/更新扩展后，刷新力扣标签页。
- **侧栏未出现**：使用当前版本的 Edge，点击扩展图标；检查 `edge://extensions` 中扩展是否启用。公司管理的浏览器可能禁止本地加载。
- **401**：密钥不正确，重新填写并保存。
- **402**：API 余额不足，前往 DeepSeek 开放平台查看。
- **429**：调用频率或额度受限，稍后再试。
- **模型不存在**：在设置中重新获取模型列表，选择后保存。
- **网络失败**：确认当前网络能访问 `api.deepseek.com`，然后重试。插件不会修改代理设置。
- **修改源码后更新**：在 `edge://extensions` 找到本扩展并点击“重新加载”，刷新力扣网页，重新打开侧栏。
- **卸载**：在 `edge://extensions` 中移除本扩展。

## 文件说明

`manifest.json` 为扩展配置；`background.js` 管理侧栏和存储访问；`page-bridge.js` 读取编辑器；`content.js` 读取题目与页面数据；`panel.html` / `panel.css` / `panel.mjs` 提供界面；`core.mjs` 负责上下文和流式解析；`render.mjs` 负责 Markdown、数学公式与代码复制；`vendor/` 保存本地依赖、字体与许可证。

`themes.css` 定义主题配色；`appearance.mjs` 管理主题偏好与系统配色监听；`theme-boot.js` 在样式加载前恢复主题，减少首屏闪烁。新增主题时在配色、主题白名单、首屏白名单和外观选项中一起注册。

第一版专门接入 DeepSeek，暂未包含其他厂商接口、工具调用或自动加载 SKILL.md。教学规则可通过系统提示词直接修改。
