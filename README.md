# 力扣伴读 · AI Sidebar

Microsoft Edge 侧栏扩展，结合当前力扣题目、代码、选区与光标，帮助理解算法。当前版本 **0.5.0**。

## 本版新增

- **多个 API 连接**：分别保存名称、API URL、API Key、模型及接口格式，保存时启用所选连接。
- **模型选择**：通过 `/models` 获取模型目录，使用下拉菜单选择，也可手动填写模型 ID。
- **两种 API 格式**：OpenAI 兼容 Chat Completions 和 OpenAI Responses。DeepSeek 专用的 thinking 参数仅发送到 DeepSeek 官方地址。
- **ChatGPT 订阅入口**：独立浏览器授权、本地凭证续期、账号切换、账号模型目录与 Responses 流式回答。
- 保留四套主题、跟随系统、Markdown / KaTeX 渲染、按题保存对话、输入草稿及最近 4 轮模型上下文。

并非任意 URL 都是兼容的模型接口。Anthropic 原生 Messages、Gemini 原生 generateContent、Azure 专用鉴权、仅接受非流式输出的接口等尚未适配；使用它们的 OpenAI 兼容地址或网关时，以服务商实际支持为准。模型目录可能包含不能聊天的模型，请选择文本生成模型。

## 安装或更新

1. 在 Edge 地址栏输入 `edge://extensions`。
2. 首次安装：开启“开发人员模式”，点击“加载解压缩的扩展”，选择直接包含 `manifest.json` 的目录。ZIP 应先解压。
3. 更新：覆盖原来加载的目录，再点击扩展的“重新加载”。**无需卸载**，然后关闭并重新打开侧栏、刷新力扣页面。
4. 打开一道力扣题，点击工具栏中的“力扣伴读 · AI Sidebar”。

扩展引用磁盘中的目录，不要在安装后移动或删除它。0.4 的 DeepSeek 设置与密钥会迁移为独立连接；对话记录和外观设置保留。默认仅浏览器会话保存的密钥在重新加载扩展后可能需要重新输入。

## API 模式：不需要本地连接程序

在 **设置 → 模型 → API 连接** 中：

1. 选择已有 API，或点击“新增”。
2. 填写连接名称、API URL 和 API Key。URL 是服务商提供的基础地址，保留 `/v1` 等路径；也可粘贴以 `/chat/completions` 或 `/responses` 结尾的地址，插件会移除末尾接口路径。
3. 选择接口格式。大多数兼容服务使用 Chat Completions；使用 Responses 的模型请选择对应格式。
4. 点击“获取模型”，允许 Edge 访问你填写的服务商地址，再从下拉菜单选择模型。若服务商没有 `/models` 接口，可手动填写模型 ID。
5. 点击“保存模型与教学设置”。

示例基础地址：DeepSeek `https://api.deepseek.com`；OpenAI API `https://api.openai.com/v1`；本地兼容服务可用 `http://127.0.0.1:端口/v1`。远程服务要求 HTTPS。本地无鉴权服务可留空 Key。

各连接的密钥绑定到该连接和完整基础 URL；修改地址会清空当前密钥输入，避免把旧服务的密钥发给新地址。“清除此 API 的密钥”只处理当前编辑的连接。默认密钥保存到浏览器会话，勾选“记住密钥”才持久保存到扩展本地存储，不使用云同步。

## ChatGPT 订阅模式

本模式参考并适配 [WillQvQ/dsh-chatgpt-plan](https://github.com/WillQvQ/dsh-chatgpt-plan) 的官方 Sign in with ChatGPT 授权实现，不需要 DSH，不读取 Codex、Pi 或其他应用的登录文件，也不读取 ChatGPT 网页 Cookie。

浏览器扩展不能直接运行本机 HTTP 登录回调，因此需要配套的 **本地连接程序**。普通 API 模式完全不依赖此程序。

### 首次使用（Windows）

1. 确认已安装 [Node.js](https://nodejs.org/) **24.5 或更新版本**。不需要 `npm install`。
2. 双击本目录下的 `companion/start.cmd`。保持该窗口运行；关闭窗口会停止订阅连接。
3. 在启动窗口复制“本地连接码”。这只用于侧栏与本机程序配对，**不是 API Key，也不是 ChatGPT token**，不要公开分享。
4. 打开扩展 **设置 → 模型 → ChatGPT 订阅**，粘贴连接码。可选择在本机记住连接码。
5. 点击 **Continue with ChatGPT**，允许访问本地连接地址。程序打开 OpenAI 官方授权页，在那里自行登录，并授权“力扣伴读”使用套餐。
6. 授权完成后返回侧栏。状态会自动刷新；也可以点“刷新登录状态”。选择账号与套餐模型，必要时点“刷新模型”，最后保存。
7. 返回题目发送问题，回答显示在侧栏。实际模型访问和额度由 OpenAI 账号、套餐、工作区权限及当前开放范围决定；模型列表不是额度承诺。

以后使用：启动 `companion/start.cmd`，再打开侧栏。独立授权记录与稳定的本机标识会保留；凭据按需续期。“添加账号”进行独立授权，“退出所选账号”尝试撤销该账号的续期会话并清除本地凭证。不会自动轮换账号或合并额度。可在 [ChatGPT 用量设置](https://chatgpt.com/settings/usage) 管理授权用量。

### 本地程序与网络

- 只监听 `127.0.0.1:18765`，校验 Host、浏览器 Origin 与随机连接码；不是局域网服务，也不是开放中转站。
- 账号、凭据和连接码保存到 `%LOCALAPPDATA%\LeetCodeAISidebar\chatgpt`，与仓库分离。Windows 启动时限制目录继承权限，授权当前用户与 SYSTEM。凭据是受文件权限保护的本地文件，不是加密保险库；不要上传该目录。
- OAuth 使用独立动态注册、PKCE、state、nonce、ID Token 签名 / 身份 / 有效期验证；未授权套餐使用时不进行推理。
- 密钥和 OAuth token 不发送给力扣网页；ChatGPT token 留在本地程序中，不交给扩展。扩展仅保存本机连接码。
- 本地程序固定向 OpenAI 官方授权、模型和 Responses 端点连接。请求被限制为文本推理，不开放命令执行、文件读取或任意 URL 代理。
- 启动脚本优先沿用 `HTTPS_PROXY`；否则尝试读取 Windows 当前启用的简单 HTTP 系统代理地址，仅应用于子进程，不修改系统代理。PAC / SOCKS 需要另行配置兼容的 HTTP(S) 代理环境变量。浏览器登录使用 Edge 自己的网络设置。

## 刷题与外观

- 选中代码后问“这里是什么意思”，或把光标放到某一行再提问；也可以直接提到变量、表达式或行号。
- 发送前会读取最新代码与题目；“查看将发送的上下文”可核对内容。页面脚本不能向模型发出指令，页面文本仅作为待分析数据。
- 若显示“仅屏幕可见代码（不完整）”，展开“手动提供完整代码”并粘贴。手动代码按题保存，不会随网页自动变化。
- 切到普通网页只暂停页面读取，不清空对话。不同题目的消息、草稿和手动代码分别保存；重启浏览器后回到相应题目恢复。
- 切题或关闭侧栏会中止正在生成的回答并保留已收到内容。切换模型保留已有历史，后续发送会把最近对话交给所选服务商 / 账号。
- Ctrl+Enter 发送，Enter 换行；可点击停止。模型设置保存时需要等待回答结束或先停止。
- 设置 → 外观提供浅色、石墨深色、暖纸、雾紫和跟随系统；选择即自动保存。
- 设置 → 教学可编辑系统提示词，例如要求“只给提示”；修改后保存。

同题在多个窗口同时编辑仍可能互相覆盖，建议在一个侧栏中继续同题。存储失败会明确提示，不会自动清除其他题目的对话。

## 数据与权限

页面读取仅限 `leetcode.cn/problems/*` 与 `leetcode.com/problems/*`，不自动运行或提交代码。新增 API 主机通过 **可选权限** 按需授权；声明 `https://*/*` 并不等于安装时获得所有网站访问权限。页面内容脚本仍仅在力扣题目页运行。

点击发送会把本题正文、代码、选区 / 光标、可读取的测试区、当前问题和最近 4 轮有效对话传给选定服务。API 模式直接连接用户配置的地址；订阅模式经本机程序连接 OpenAI 官方服务。没有开发者服务器、统计或额外上传。

渲染库和字体本地打包，禁止模型原始 HTML、脚本、外部图片执行 / 加载。代码上限 60000 字符，题目 22000 字符，测试区 10000 字符；不完整状态会传给模型。

## 排错

- **新地址访问被拒绝**：在设置中再次保存或获取模型，按 Edge 提示授权该地址。
- **模型列表失败**：确认 API URL 保留了服务商要求的路径；服务商可能未提供 `/models`，可手动填写模型 ID。
- **400 / 404**：核对接口格式、基础地址和模型 ID；该模型可能不支持选定协议。
- **401 / 402 / 429**：分别检查密钥或登录、API 余额、用量限制；不要把套餐授权额度与普通 API 余额混为一谈。
- **无法连接本地程序**：先启动 `companion/start.cmd`，保持窗口打开，核对本地连接码；端口被占用时检查是否已有实例运行。
- **登录完成但没有模型**：检查是否允许套餐使用、账号资格和网络，点击刷新登录状态 / 刷新模型。
- **登录取消或超时**：点击“取消等待登录”，然后重新登录。不需要复制任何其他应用的 token 文件。
- **凭证无法续期**：临时网络故障会保留仍有效的凭据；到期或撤销后需重新授权。退出时远程撤销未确认，会明确提示你在 ChatGPT 设置断开应用。
- **安装后无法读取页面**：刷新力扣网页，再关闭并重新打开侧栏。力扣编辑器内部实现改变时可能需要更新适配。

## 开发与验证

扩展无构建步骤，渲染依赖已随源码提供。Node.js 测试：

```sh
node --test tests/*.test.mjs
```

测试覆盖对话持久化、页面读取、Markdown / 数学公式、主题、配置迁移、凭据隔离、两种流式协议、OAuth 身份与权限检查、取消登录、续期、账号隔离、本地连接鉴权与请求范围。

0.5.0 已在本机执行自动测试、Windows 本地程序启动测试及 400px 侧栏的模拟 API / 模拟授权交互验证；**尚未使用真实 API 密钥或真实 ChatGPT 账号完成端到端推理测试**。Edge 的真实新增主机权限弹窗也需在更新后由用户操作验证。

`providers.mjs` 负责 API 配置和协议；`model-settings.mjs` 负责模型 UI；`companion/` 提供订阅连接；其他界面、页面读取和对话模块延续 0.4。第三方源码来源、版本、改动与许可证见 [companion/THIRD_PARTY.md](companion/THIRD_PARTY.md) 及 `vendor/`。
